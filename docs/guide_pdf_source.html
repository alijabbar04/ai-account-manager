API Usage Tracking Guide

Why the API-key usage pages can look empty, and every way to make them work — including the locally-measured ledger that is already wired in and needs no special key at all.

Written 15 July 2026 · applies to AI Account Manager 1.1 and later

1Why the pages show nothing

The app asks each provider's billing API for your spend. For most providers that data is simply not offered to normal API keys — it is a provider-side restriction, not an app bug. A standard key can prove it is valid (the app checks the models endpoint), but the usage endpoints answer 401/403.

ProviderNormal keyWhat real usage data needs
Anthropic✗ validate-only An Admin key (sk-ant-admin…) for the organization cost & usage reports
OpenAI✗ validate-only An Admin key (sk-admin-…) for the organization costs & usage endpoints
Gemini (AI Studio)✗ impossible No usage/billing API exists for API keys at all — only GCP Cloud Billing export + OAuth
OpenRouter✓ works fully Nothing — a normal sk-or-… key reports spend and balance

2Fix 1 — locally measured usage Recommended · already wired in

The "Measured locally" panel on the Anthropic provider page

Several in-house desktop tools write to a shared usage ledger: each one records the exact usage block returned by the API on every call into

%APPDATA%\LiftedPDFTools\api_usage*.jsonl

These are real token counts straight from Anthropic — not estimates — and the panel reads them live: past 24 hours / 7 days / 30 days / lifetime spend, broken down per app. Each app also has its own analytics page, and Stage 2's page adds a per-tool breakdown.

Coverage: every call made through those apps on this machine. What it can't see: calls made with the same key from other machines or tools. For a single-PC workflow this is effectively complete.

3Fix 2 — an Anthropic Admin key Organization accounts only

  1. Go to console.anthropic.com → Settings → Organization → API keys.
  2. Create a key with the Admin role — it will start sk-ant-admin…. (If you never see an Admin option, your account is an individual account and Anthropic does not offer admin keys for it — use Fix 1.)
  3. In this app: API Keys → Add key, paste the admin key — it is auto-detected from the prefix.
  4. Refresh — cost & usage now come from Anthropic's own organization reports (org-wide, all keys, all machines).
Treat an admin key like a password: it can read org-wide billing. Prefer a spend-capped, analytics-only workflow and never paste it into other tools.

OpenAI: same idea — create an Admin key (sk-admin-…) from platform.openai.com → Settings → Organization → Admin keys, then add it here.

Gemini: no key-based option exists. Track spend via Google Cloud Billing budgets/exports, or route Gemini calls through OpenRouter (whose key reports usage properly).

4Which numbers should I trust?

Admin-key numbers — authoritative org-wide billing, all machines.

Locally measured numbers — exact for everything done through the desktop apps on this PC, blind to anything else.

If both are present they differ exactly by usage from outside this machine — that difference is itself useful information.

5Known gap that remains

Even with an admin key, charts backfill only from the moment a key is added — the adapters don't implement history backfill, so day-one charts start sparse and fill as snapshots accumulate.
